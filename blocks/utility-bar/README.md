# Utility Bar

Thin brand strip rendered above the header (ship-to, support, sign-in links). Pure CSS/content block, no drop-in dependencies.

## Content model

- Row 1: portal label (plain text)
- Rows 2+: one link (or plain text) per row

## Configuration

None — all content is authored.

## Integration

No URL parameters, localStorage, or events. No drop-in dependencies.

## Behavior

Static on all viewports; horizontally scrollable on very narrow screens instead of wrapping.
