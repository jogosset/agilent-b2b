# Stats

Spec-sheet style strip of 2–4 numbers with labels (e.g. "6,214 — SKUs in stock today").

## Content model

Collection block — one row per stat, 2 cells: number, label.

## Configuration

None — all content is authored.

## Integration

No URL parameters, localStorage, events, or drop-in dependencies.

## Behavior

2-column grid on mobile, 4-column at 720px+. No interactive states.
