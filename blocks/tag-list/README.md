# Tag List

Row of pill-shaped chips (e.g. industries served), each linking to a curated catalog.

## Content model

Collection block — one row per chip, 1 cell containing a link (or plain text if not linked).

## Configuration

None — all content is authored.

## Integration

No URL parameters, localStorage, events, or drop-in dependencies.

## Behavior

Wraps to multiple lines as needed; chips highlight on hover when linked.
