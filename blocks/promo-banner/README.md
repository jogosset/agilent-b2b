# Promo Banner

Single-row teaser strip: a tag, a heading + description, and a CTA link. Reused across the homepage for both the quick-order teaser and the application-note callout.

## Content model

Standalone block, 1 row, 2 cells: tag text, rich text (H3 heading + description paragraph + a paragraph containing only a link, treated as the CTA).

## Configuration

None — all content is authored.

## Integration

No URL parameters, localStorage, events, or drop-in dependencies.

## Behavior

Stacked on mobile, tag | content two-column layout at 860px+.
